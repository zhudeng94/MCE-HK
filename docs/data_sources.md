# 来源清单、版本与追溯

数据获取和字段解析见 [下载与导入](acquisition.md)。[本地来源清单](source_inventory.csv) 记录每个原始文件的路径、字节数、SHA-256、已知 URL、获取时间及再分发状态。当前必需输入由 `configs/required_inputs.json` 单独定义。

```bash
python scripts/inventory_sources.py
```

此命令重建清单，并校验已有来源 sidecar 的哈希。缺失的获取日期和来源记录保持明确缺失，不根据文件时间猜测。

## 生产输入

| 来源组 | 本地位置 | 维护要点 |
|---|---|---|
| C&SD | `data/raw/csd_*` | API 与历史能源报告共同提供燃料、煤气、用电和发电平衡 |
| EMSD | `data/raw/emsd_*` | 新旧表号分别记录；重叠年按已接受版次覆盖，工业保留逐版来源 |
| 运输署 | `data/raw/td_*`、`traffic_census_*` | 固定隧道面板、车辆燃料份额、年度车公里及渡轮客流 |
| HKIA / 海事处 | `data/raw/airport_*`、`marine_*` | 月度活动用于供油分配；历史约束与近期暂估身份分别记录 |
| 两电资料 | `data/raw/power/HK_power_generation_2010_2025.xlsx` | 公司和半年原表含来源 URL；用于近期电力混合更新 |
| 香港 CRT | `data/raw/inventory/` | 2021 校准，2005/2020 留出；导出具体工作表、单元格及哈希 |
| CEIC | `data/raw/legacy/HK.xlsx` | 2005–2012 油品月度总需求代理；保留其统计边界 |
| IPCC / EPD | 参考 PDF 与配置来源字段 | 因子、单位、假设和引用共同维护 |

两电资料的 CLP 2011 年后采用净送出；2010 年年报发电口径独立保存。CLP 负的净送出值保留。港灯必须有两个半年才能生成完整年度，煤与油保持合并。当前半年的更新只用于实际有观测且半年已经结束的月份，不赋予未观测公司同样变化。

## 可选输入与历史材料

Climate TRACE 和其他外部清单缓存用于可选比较。目录中的检索 HTML、探测和参考文本记录获取背景，其存在不表示计算依赖。

旧方法说明和审阅归档至 `local/archive/method-history/`；网站与部署说明在本地 `local/docs/`。现行计算方法以本目录的基准、部门公式和复现说明为准。

## 数据包与公开代码

公开代码不携带生产原始快照。下载脚本可以获取目录内已配置的公开来源；CRT、CEIC、两电历史汇编仍需按获取指南导入。CEIC 工作簿及派生序列的再分发授权尚未记录；CRT 原始获取记录仍需补全。准备公开数据包时逐来源记录许可和归属，保留实际使用版本。

`data/processed/` 是可重建标准化输入，不能手工编辑它来修改排放结果。输入、代码和参数哈希存于各阶段 manifest；近期修订历史应与发布结果一起保存。
