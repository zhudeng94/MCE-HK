# 现行方法与实现

维护方法从以下四页开始：

1. [下载与导入](acquisition.md)：原始文件、字段、单位和获取方式。
2. [基准与部门映射](benchmarks.md)：CRT 类别、来源单元格、校准年及范围。
3. [分部门公式](sectors.md)：燃料/活动到排放的计算链及代码位置。
4. [分步复现](reproduction.md)：每一步的输入、输出和检查顺序。

工程职责见 [架构](architecture.md)，字段解释见 [数据字典](data_dictionary.md)。

现行模型以 2021 CRT 为唯一部门基准。工业采用年度非电力能耗及 2021 CO₂/TJ 系数；道路与剩余运输、本地航运分开发布；总量在所需部门完整时计算。近期季度暂估、公司混合更新和不确定性处理见部门公式。

`outputs/report.md` 为可选生成的结果报告，现行方法不依赖其预先存在。历史方法审阅和改造前文件保存在本地整理档案；当前实现以 `src/cmhk/`、根目录方法参数及 `configs/sector_mapping.json` 为准。
