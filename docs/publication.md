# 代码与数据发布准备

日常直接在项目目录使用 Git，`.gitignore` 排除 `local/`、数据、输出和缓存。上传前检查待提交列表即可。`python scripts/export_code.py --destination <新目录>` 是可选快照工具，使用同一份忽略规则，并附逐文件哈希。

代码仓库：[zhudeng94/MCE-HK](https://github.com/zhudeng94/MCE-HK)。`main` 分支包含计算代码、参数、文档和 README 图件。

## 发布物

| 发布物 | 内容 |
|---|---|
| 代码仓库 | `src/cmhk/`、方法参数、来源/部门目录、测试与现行文档 |
| 月度数据产品 | `outputs/publication/MCE_HK_monthly.csv`、生成的 README 及 manifest |
| 复现输入包 | 当前版本必需原始文件与来源 sidecar，按获取和分发权限提供 |
| 支持材料 | 诊断、不确定性和比较结果，单独版本化 |
